# Data card: tinybench synthetic scenes (v1.1)

Datasheet format after Gebru et al., "Datasheets for Datasets" (CACM 2021).

## Motivation
- **Purpose.** Test methods that find tiny groups (2–9 points) in unlabelled data, beside a near-duplicate mass, at
  matched false-group rates, with an oracle ceiling.
- **Gap it fills.** Standard clustering suites have no groups this small; rare-cell and microcluster papers each use
  their own data and metrics.
- **Who made it, funding.** The authors of the accompanying paper (names withheld in this draft).

## Composition
- **Instances.** A scene = about 1,600–2,000 points in 20 ambient dimensions.
  - Near-duplicate mass: 30 templates × 30 near-copies (sd 0.02).
  - 8 Gaussian background clusters of 30–150 points (sd 0.3–0.8), centres kept apart.
  - 2% uniform noise in the bounding box.
  - 12 planted groups of 2–9 points.
- **Tiers.** Placement (isolated, touching, inside) × contrast (high 0.25, mid 0.5, low 1.0) = 9 tiers; intrinsic
  dimension d = 2, 5, 10, mapped to 20 dimensions by a random orthonormal map plus noise of sd 0.002.
- **Shapes (tracks).** iso (v1.0), aniso (power-law spectrum, random orientation), t3 (Student t, 3 df), boot
  (offsets of real public rare groups, `data/offsets_v1.npz`). Same skeleton, centres, sizes and total variance
  across shapes for a seed, so tracks are paired.
- **Labels.** Per point: kind (mass, background, noise, group) and planted group id. Complete and exact by construction.
- **Splits.** Frozen seed lists in `tinybench/seeds.py`: v1.0 dev 400–404, test 500–504; v1.1 dev 600–604, test
  700–704. Never tune on test seeds.
- **Sensitive content.** None. No people, no real records (except the shape library, see the boot card below).

## Collection process
Generated by `tinybench.generator.make` from a NumPy seed. No collection, no consent issues.
The boot shape library holds only member-minus-centroid offsets (shapes) of 20 public rare groups: 8 from 10X PBMC
(16 cells each, PCA 50) and 12 KDD Cup 99 rare attack types (PCA 20). Built by `scripts/build_offsets.py`.

## Preprocessing
None beyond the generator. Points are not standardised.

## Uses
- **Intended.** Benchmarking tiny-group / microcluster / rare-cell detectors; recall at ≤ 0.25 and ≤ 0.5 false
  small groups per 100 points; comparison with the oracle scan.
- **Not intended.** Claims about real-data recall on their own. Planted isotropic groups are easier than real ones:
  on single-cell they inflate recall 5–7× (stage-7 realism study). Report a real-group track next to any synthetic
  number.
- **Known biases.** The background is a Gaussian mixture; real backgrounds have manifolds, heavy tails and batch
  effects. The oracle is a local-scan ceiling, not an absolute limit (on inside/low a method that collapses the
  near-duplicate mass beats it).

## Distribution and maintenance
- Licence: generated data and offset library CC BY 4.0; code MIT (see LICENSE). Data derived from third-party sources keeps the upstream terms named in `kdd99.md` and `pbmc10x.md`.
- Versioning: semantic. Changing any released seed list or the generator's output for a released shape is a major
  version change. A test pins shape="iso" to the published generator bit for bit.
