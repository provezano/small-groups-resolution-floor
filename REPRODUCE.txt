2b. GAPCLUST IS NOT IN THIS DEPOSIT (licensing constraint, not a missing result)
   The official GapClust R package (github.com/fabotao/GapClust) is declared GPL-3 and has no LICENSE file. The Python ports of it
   that were used for the paper (clustering/eval/nature/tiny_baselines.py, p3_gapclust_full.py, and the copy in tinybench) are derived
   works and cannot be distributed under this deposit's MIT licence, so they were removed. gapclust_raw, gapclust_groups,
   gapclust, gapclust_sweep and the functions of p3_gapclust_full are stubs that raise GapClustUnavailable with an explanation.
   To use them: obtain the official package, write your own port in a Python file defining
   gapclust_raw(Z, k, squared) -> (skew, top_ave, v1k, idx) and gapclust_groups(skew, top_ave, v1k, idx, thr), and set GAPCLUST_PY.
   (Stub delegation was checked with a trivial dummy file; no GapClust logic was run.)
   Stored results made with the removed port are kept, but CANNOT be regenerated from the bundle alone:
     tinybench/results/leaderboard_v1.0_s500_cap0.25.{json,md} and ..._cap0.5.{json,md}: rows gapclust_port, gapclust_port_k30,
       gapclust_official_sq, gapclust_official_sq_k30
     results/pass2_frontier_stats.json, pass2_perscene_s800/s810/s820.json: gapclust_port_k30, gapclust_official_sq_k30
     results/audit_recheck.json: gapclust_port*, gapclust_official_sq_k30, gapclust_k30 families
     results/rgt_real_a.json, rgt_real_b.json, rgt_predicted_vs_actual.json: gapclust_k30
   The statistics and figures that only READ these stored files (make_figures.py, audit_recheck --only pass2 on the shipped
   per-scene files) are unaffected. Any runner that CALLS GapClust (run_kdd, run_sc, scale_real, rgt_real, p3_tracks, tail_bench,
   p3_perscene, pass2_frontier, ...) fails at that call unless GAPCLUST_PY is set.
   Other baselines: see SCAN_REPORT_v3.txt, "Third-party baselines".

   PYTHONPATH=. python figures/skl_compare.py         writes out/fig4_sklearn_planted.png, out/sklearn_compare.json
                                                      [RAN: finishes in seconds.]
   WHICH FIGURE IS WHICH: figures/paper/fig_opening_sklearn.png is the figure printed in the paper. It was produced
   before the fringe fix (a later correction to how near-duplicate points are handled in the method, tiny_methods.py,
   option fix="joint"). skl_compare.py calls the method as shipped, i.e. with the fix, so its output is the corrected
   version and it differs from the paper figure. The difference comes from that fix; it is not a discrepancy in
   the paper's result, and the pre-fix version is not reproduced here. The two images were not compared pixel by pixel.

5b. NETWORK ACCESS (public data fetched on demand)
   Command: python -m clustering.eval.nature.run_kdd   (no arguments; the module has no argparse, so ANY argument,
   including --help, starts the analysis and the download).
   What it fetches: the KDD Cup 99 "10 percent" file through scikit-learn fetch_kddcup99, about 3.1 MB, from its
   original public host, into the folder given by TG_DATA (default: data/ in the deposit root). Nothing is uploaded or sent.
   Other loaders (scale_data, scale_real, tinybench real tracks) likewise fetch public data sets on first use.
   The depositor's checking run triggered this once by accident; the file was deleted afterwards.

   tinybench_cli --help ; rgt_real --help                                              [SYNTAX: argparse help only]
