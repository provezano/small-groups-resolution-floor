Code and benchmark generator for the paper
"Small groups below the resolution floor: masking, a detection boundary, and an exact scan"
Felipe Provezano Coutinho (ORCID 0000-0001-7206-5856)

What this is
------------
The paper studies groups of 2 to 15 points that density-based clustering cannot see (it calls the effect masking),
proves where detection becomes possible, and gives an exact test (CTS) that scans neighbourhoods of each point
under a density-free null. This deposit holds the code behind the paper's experiments and figures, the generator of
the synthetic benchmark it uses (tinybench), and a few stored result files.

Layout
------
clustering/eval/nature/   the implementation: the benchmark scenes, the method (tiny_methods.py, cts3), the baselines,
                          the paired-bootstrap statistics, and the runners for each experiment
clustering/tests/         unit tests of the shipped modules (pytest)
tinybench/                the benchmark generator as an installable package, with its own README, data cards and tests
figures/                  make_figures.py (figures 2 to 4), skl_compare.py (figure 1), rgt_predicted_vs_actual.py,
                          and figures/paper/ (the four figures as used in the paper, for comparison)
results/                  stored result files read by the figure scripts and by the analysis step
requirements.txt          the package versions the tests and figure scripts were run with
REPRODUCE.txt             the commands, and which of them were run end to end

Figures
-------
Figures 2 to 4 are regenerated by figures/make_figures.py from the stored files in results/. Figure 4's 18 plotted
values are typed into the script; figures/check_fig4_cells.py compares them with results/p1math_null.json.
Figure 1 is made by figures/skl_compare.py; the copy in figures/paper was made before a later correction of the
method, so a regenerated Figure 1 differs from it (see REPRODUCE.txt). Running some runner modules fetches public data
sets (see REPRODUCE.txt, "Network access").

Not included
------------
- GapClust. The official package is GPL-3, so the Python ports of it were removed from this MIT deposit (clustering/eval/nature/tiny_baselines.py,
  p3_gapclust_full.py, tinybench baselines). The functions are stubs that raise GapClustUnavailable; point GAPCLUST_PY at your own port to use them.
  Stored GapClust results are kept; they cannot be regenerated from the deposit alone.
- The public data sets (KDD Cup 99, single-cell data, OpenML tables, and so on). The loaders download them from
  their original hosts on first use; set TG_DATA to choose the folder. Their licences are those of the sources.
- Per-scene result files of the other experiment families and the scripts that summarise them.
- A few baselines need external tools (a Java and an R toolchain for the original McCatch and GapClust code); the
  code paths exist, the tools are not shipped.
- An optional few-label diagnostic that belonged to another project was removed from tiny_bench.py (it needed two
  modules that are not part of this deposit); nothing in the paper's experiments used it.
